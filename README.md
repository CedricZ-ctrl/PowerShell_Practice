# PowerShell Starter Toolkit

Welcome to this collection of beginner-friendly PowerShell scripts designed to help you automate and manage your Windows system effortlessly.

## 🚀 What’s Inside?

This repository offers a variety of practical scripts covering key Windows administration tasks, such as:

- **Monitoring and managing processes and services**  
- **Automating task scheduling**  
- **Backing up and restoring the registry**  
- **Creating structured directory trees for your projects**  
- And more scripts designed to simplify your daily sysadmin tasks!

Each script is **well-commented** with clear instructions and easily customizable variables, so you can tailor them to your environment and needs.

## 🎯 Who is this for?

- Beginners looking to learn PowerShell and Windows administration basics  
- System administrators who want quick, ready-to-use automation scripts  
- Anyone interested in improving their Windows automation skills  

## ⚙️ How to Use?

1. Clone or download this repository  
2. Review each script’s variables (highlighted in uppercase comments) and modify them as needed  
3. Run the scripts in PowerShell with appropriate permissions  
4. Check the generated log files for detailed execution info  

## 📚 Scripts Overview

| Script Name              | Description                                                  |
|--------------------------|--------------------------------------------------------------|
| `CheckProcess.ps1`       | Checks if specified processes are running, restarts if stopped |
| `CheckService.ps1`       | Verifies Windows services status and starts stopped services  |
| `RegistryBackup.ps1`     | Creates or restores registry backups                          |
| `CreateTaskSchedule.ps1` | Creates scheduled tasks to automate script execution          |
| `Toolkit.ps1`            | Creates a customizable folder structure for projects          |
| 'CheckBitlocker.ps1'     | Check if disks is encrpyted, if not then Enable bitlocker
